# Session Log — May 19, 2026

## Chrome Extension: TikTok Analytics Exporter

### What we built

A personal Chrome extension (`tiktok-analytics-exporter/`) that intercepts TikTok Studio's internal API calls and exports analytics data as CSV. The extension targets the creator's own account only — no scraping, no third-party access.

Architecture: injected page script intercepts `fetch`/`XHR` → content script relays via `postMessage` → service worker orchestrates collection and export → popup UI drives the flow.

### What we fixed today

**Bulk export was broken.** The video list collection phase wasn't reliably extracting video objects from the API response. Fixed with a multi-path fallback that tries four different response shapes before giving up, and snapshots the raw payload structure to the debug tab for inspection when it fails.

**CSV fields were blank.** Caption, duration, likes, and shares were not being captured. Traced the issue: `extractItemFields` in the service worker wasn't pulling those fields from the video list API response. Fixed extraction and wired fallbacks into `ingestVideoList` so insight-phase parsing can use them.

**NAWP was always blank.** The calculation (`avgWatchTimeS / durationS`) was silently failing because `durationMs` wasn't resolving from the insight response. Extended the fallback chain to pull `duration_ms` from the earlier video list collection phase, which does carry it reliably.

**Post time was missing.** Added a `post_time` column (`HH:MM:SS`) derived from the Unix timestamp on each video, alongside the existing `post_date` column.

**Date filter had timezone ambiguity.** Fixed `filterVideosByDate` to handle local-vs-UTC edge cases.

**Promise leak on page-fetch timeout.** The timeout callback wasn't being cleared when a reply arrived. Fixed by storing the timer reference and cancelling it on reply.

### Positioning change

Reframed the extension from a "research data collection tool" to a **personal creator analytics tool** — the popup copy, page warning, and README all reflect this. The extension collects data from the creator's own TikTok Studio dashboard for their own analysis, not for a study.
